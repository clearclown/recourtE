# recourtE

> **本リポジトリは [tukiminya/recourt](https://github.com/tukiminya/recourt) のフォークです。**
> オリジナルプロジェクト「再考裁」の理念に基づき、個人的な拡張・実験を行っています。

日本の最高裁判所の判例情報をわかりやすく説明するためのウェブアプリケーションです。

## フォークでの追加機能

- 裁判官詳細ページの情報拡充（学歴・経歴・写真・外部リンク）
- 最高裁HP からの裁判官情報自動スクレイピング (`enrich-judges`)
- ローカル LLM (LM Studio) による裁判官紹介文生成
- Podman Compose によるローカル開発環境（LibSQL + フロントエンド）

## Features

- 最高裁判所の判例情報を収集し、わかりやすく表示
- 生成 AI による判例の要約・解説
- 裁判官ごとの関与判例・スタンス傾向の可視化

## Inspiration

本プロジェクトは [チームみらい](https://team-mir.ai/) が提供する「[みらい議会](https://gikai.team-mir.ai/)」から着想を得て開発されました。
複雑な情報を民間向けにわかりやすく提供するという理念を先駆したチームみらいに敬意を表します。
